# MSCS532_Assignment1
Insertion Sorting

## Overview
This is a quick Python implementation of the Insertion Sort algorithm, modified to sort an array in descending order (largest to smallest) instead of the standard ascending order.

## Objectives
* Walking through and understanding the insertion of sort mechanics.
* Tweak the standard loop condition to sort in reverse.
* Push multiple commits to GitHub to practice basic version control.
